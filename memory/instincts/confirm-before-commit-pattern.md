## Action
在提交前主动确认用户是否授权提交，不要默认执行提交操作

## Evidence
用户说'要现在 commit 这个文档吗（仓库规矩是不提前授权不提交...按你的规矩我确认一下）'，表明用户期望在提交前获得确认。
